## 🏛️ Acerca de CAPNEXS

**CAPNEXS** es la firma y capa de inteligencia financiera del ecosistema Payote Group. Conecta inversionistas, banca privada, estructuración de hipotecas y financiamiento inmobiliario en la República Dominicana y el Caribe mediante una combinación de tecnología, analítica avanzada, inteligencia artificial y relaciones bancarias de élite.

---

## ⚡ Características Principales

- **Experiencia 3D WebGL (Three.js)**:
  - *Hero Financial Nexus*: Esfera cuántica armilar interactiva con física elástica de cursor y más de 1,200 partículas de flujo de capital.
  - *Ecosistema Payote en 3D*: Órbita espacial interactiva que conecta las marcas del grupo (*Dream, CAPNEXS, Avranza, Alenza, Acougos, Ocevia, Payote Luxury*).
  - *Emblema VIP Private Client*: Tarjeta 3D con reflejos metálicos dinámicos.
- **CAPNEXS Financial Desk en Tiempo Real**:
  - Monitor continuo de Divisas (USD/DOP, EUR/DOP, EUR/USD), Bolsas Globales (S&P 500, NASDAQ), Commodities (Oro, WTI), Criptoactivos (BTC, ETH, SOL) e Indicadores del Sistema Financiero Dominicano (TPM del Banco Central, Tasas Hipotecarias y Liquidez).
- **Suite de 6 Herramientas Financieras Propietarias**:
  1. **Calculadora Hipotecaria Avanzada**: Cuotas, amortización, LTV e impacto en DTI en USD y DOP.
  2. **DTI (Debt-to-Income) Analyzer**: Velocímetro radial y diagnóstico de capacidad de endeudamiento.
  3. **CAPNEXS SCORE™ & Precalificador**: Algoritmo propietario de evaluación crediticia preliminar (0 a 100).
  4. **Currency Intelligence**: Simulación de spread cambiario interbancario vs. ventanilla comercial y alertas.
  5. **Investment Analyzer**: Modelado de ROI, Cap Rate, Cash-on-Cash y punto de equilibrio para activos de lujo.
  6. **Financial Health Check**: Diagnóstico de resiliencia patrimonial en 2 minutos.
- **NEXA AI Desk**: Sistema multi-agente (*Mortgage Advisor, Financial Analyst, Dominican Regulation & KYC/AML, Investment Analyst*).
- **Audio Feedback Táctil**: Web Audio API para micro-interacciones acústicas de lujo.
- **Bilingüe**: Selector dinámico Español / Inglés.

## 🛠️ Stack Tecnológico

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons
- **3D Graphics**: Three.js (WebGL Canvas)
- **Tooling**: Vite
- **Efectos**: Canvas-Confetti, Web Audio API

## 🚀 Instalación y Desarrollo Local

```bash
# Clonar repositorio
git clone https://github.com/bilito65/capnexs.git
cd capnexs

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
